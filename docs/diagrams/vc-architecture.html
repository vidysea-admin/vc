① System overview — who connects, what runs, where data lands

Partners (Vidysea website, Pathlynks) connect with an API key; students can also sign in with a JWT or chat anonymously; counsellors use the web app. One API process serves all public routes behind nginx.

Tenancy: a partner's server key reaches only the tenant named by its own partner id (chat.ts:854-855, voice.ts:1711-1712). Partner ids that equal or look like a real tenant are refused when added and on every request (VC_RESERVED_TENANT_IDS, VC_PARTNER_OWN_TENANTS).
Go-live gate runs once at startup, not per request: a refused gate means the API does not start (index.ts:636-652).
Counsellor web does not call the API; it runs the scribe graph in-process (apps/web/src/server/runtime.ts), in demo mode unless VC_WEB_MODE=live.
Not production-ready yet: Gemini Live is compile-only and the launcher builds no live voice provider, so real voice needs a wiring step. Rate limits, single-use voice tokens and crisis slots are in memory, so they hold for one process only.

② One student chat turn — guards first, then the answer graph

Same path for a signed-in student and a partner server key. Crisis text always wins: it skips rate limits and gets a fixed helpline reply with no model call. Anonymous chat runs the same graph with search only and stores no text.

Knowledge order: search_kb first; a signed-in student also gets ask_knowledge_base when search finds nothing. Only when no sourced claim survives does the no-source path run (Gemini grounding when VC_GROUNDING=gemini, else a model-only expert answer), always with a disclaimer.
Minors: a missing age counts as a minor. Without guardian consent the student gets a fixed reply and nothing is stored except ids and timestamps.
Anonymous chat (/v1/public/chat/turns): no tenant and no DB, search only. Only a text-free counter row is written (anonymous.ts:447-541).

③ One voice session — mint a token, open the stream, mute on crisis

Every check runs before the WebSocket is accepted. A crisis phrase mutes the model and plays fixed helpline audio. Audio is never stored.

Go-live: voice is gated by A10. It runs on Umesh's D-111 owner override only when VC_GATE_APPROVER is set in the environment.
Gap: main.ts builds no Gemini Live provider or crisis audio yet. With VC_VOICE_ENABLED=true and nothing injected, startup refuses (index.ts:650). Real voice needs this wiring plus a real-audio test.
Anonymous voice keeps no turn text, audio, usage or resume log. A crisis only bumps a text-free counter.

④ Counsellor scribe — session transcript to an approved Student Knowledge Graph

The AI proposes and the counsellor decides. Nothing reaches the knowledge graph without counsellor approval (a LangGraph interrupt).
