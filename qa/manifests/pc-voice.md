## Not verified here (for the checker)
- Origin binding design: the registry cannot look a partner up by id and partners.ts was limited to a route-set edit, so the anonymous WebSocket upgrade does not call the registry again. Instead the session mint (which authenticated the page key and checked the browser Origin against its allowedOrigins) embeds that origin in the signed single-use token, and the upgrade requires any Origin header to equal it. Consequences to attack: a token minted by a script with no Origin header connects without an Origin check but is refused when a browser Origin is sent; a page-key revoke does not end a 60 s token already minted (the same window as a revoke on the cached lookup).
- A real nginx (only string-checked), a real WebSocket through nginx, real Live provider audio, real playback and echo behaviour, browsers other than Chromium, a screen-reader pass. The browser audio glue uses ScriptProcessorNode (deprecated but universal); an AudioWorklet is a possible later change.
- The on-screen crisis notice in the widget is the helpline line only (14416 and 112), the same as the text chat's escalated reply (cycle 1, review 3); the crisis wording itself is the server's pre-rendered fixed audio. Hindi/Hinglish on-screen crisis wording is not provided and not claimed.
- Voice in proxy mode: the mic is not offered (no key from the page, no voice proxy route defined). A partner who wants voice uses key mode.
- Pre-existing, not caused by this unit: `tests/anonymous-route.test.ts` has 2 failing tests ("A20 state ON but gate closed: the real repo qa/gates (B13 PENDING...)" and "startApi: flag on with the real repo gates refuses to start") and then hangs, identically on the main checkout D:/vc (8e54fe8) and in this worktree; the real qa/gates have moved on since those tests were written. - The real-gates assertions (go-live-gate.test.ts: the CLI test and "V1 real gates") now evaluate the real qa/gates and require voice ALLOWED with the D-111 note while the A10 record carries the override line; they are no longer skipped (cycle 1).
