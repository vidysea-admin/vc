## Design facts
- Link = recipe `path` + `?section=` + a key of the closed `SECTION_KEYS` list; the intent only selects a recipe through an anchored pattern and is never copied into output. The only student-derived text is a country NAME from a reviewed table, echoed only when exactly one country is named and its `/country/<slug>` page is in the catalogue.
- A recipe fires only if its base path is in the synced catalogue (else `NAVIGATE_UNKNOWN_TEXT`, graph falls to KB); a locked base path gives the locked text.
- Output: headline `label: purpose (link)` + 3-6 numbered constant steps (<= 7 lines). Journey Map text states per programme, no single full journey, shortlist first, Generate Journey Map, 60-120 seconds, bulk covers counsellor-verified only.
- Every pattern is anchored at both ends; free-word slots are capped at two words; no unbounded nested quantifier.
