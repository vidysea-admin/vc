## C. REVISE findings (numbered; fix before plan-approved)

R1 (BLOCK-level, spec.md:11 A1 spec.md:28, plan.md:19, 24) The citation chain does not exist in the KB as drafted. Spec.md:11 says a `sourceId` "is a KB claim id returned by that same turn's `/ask` or `/search` call" and resolves through `GET /citations/:claimId`. Checked in D:/KnowledgeBase: `POST /ask` returns `sources.internal[].node_id` (tree-index nodes) plus optional `evidence` and `sources.web[]` (mcp/university-kb/src/kb-client.ts:38-46, 82-91 mirrors the real response); `GET /search` returns turn hits `{turnId, sessionId, score, turn, session}` (apps/api/src/routes/search.ts:13-19); only `/citations/:claimId` takes a CLAIM id (routes/citations.ts:34). Neither /ask nor /search returns claim ids, so `verified:true` as defined cannot be produced. Fix: either (a) define the VC sourceId as `node_id` / `turnId`+`sessionId` and verify against `/sessions/:id` or the `evidence` embedded in `/ask`, dropping `get_citation` from the primary path, or (b) record it as a confirmed gap G5 ("claim-id handle on /ask and /search results") that opens U1 as a real KB change request. Plan.md:19 (U2 `get_citation`) and the "none confirmed" claim at spec.md:67 and plan.md:18 must change accordingly. This is the main honesty failure for G1-G4: U2's first step is described as settling G1-G3, but a code read already shows a gap.

R2 (BLOCK-level, spec.md:10, 22, 28 A1/A4, 51 A18, 71 G3) The KB `/ask` has a Tavily web fallback (apps/api/src/ask-web-fallback.ts, packages/ask/src/ask-v2.ts:181-190; response fields `web_used`, `sources.web`, D-041 ruling 2 in the KB). The drafts' non-goal is "web or training-data answers" and A4 expects `no_sourced_answer` for an out-of-KB question, but an out-of-KB `/ask` returns a web-supplemented answer. Fix: add a VC rule "drop `sources.web` and treat `web_used:true` as `no_sourced_answer`" with a test in U2/A18, and add a gap G6 "no way to disable web fallback per request / per key" (candidate U1 KB change), and name Tavily in the B13/A15c disclosure.
