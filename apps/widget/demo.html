Partner site (demo)

This page stands in for a partner website. The chat bubble at the bottom right is the VC widget.

Mode: . Add ?mode=proxy for proxy mode (posts to /api/vc with no key). Local API: run node apps/widget/tests/stub-server.js 5174 and open http://127.0.0.1:5174/demo.html. Add ?voice=on for the Chat | Voice toggle (needs the voice add-on served next to the widget file). The panel floats: drag the header, resize from the bottom-right corner, or use the pop-out button (opens /vc-popout?site=demo on this origin). To point at a real API instead, set data-vc-api to its origin (the API must allow this page origin, K4).

Stub triggers: crisis, nosource, xss, ratelimit, revoke, slow, boom.
